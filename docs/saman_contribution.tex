Saman implemented the address decoder and the tag, valid, and data RAM modules for the direct-mapped cache. The decoder separates each 32-bit address into a 22-bit tag, 6-bit index, and 4-bit offset, with the offset split into word-select and byte-offset fields. The tag RAM provides 64 asynchronous-read 22-bit entries, while the valid RAM provides 64 resettable valid bits. The data RAM stores four 32-bit words for each of the 64 cache lines. Saman also wrote self-checking unit testbenches for all four modules, covering address extraction, writes, reads, reset behavior, disabled writes, and aliasing checks.
